🔒 System Isolation & Safety Boundaries

  • Zero External Traffic: No HTTP requests leave the application boundary. All domains (northstar.example) are internal mock routes.
  • No Credential Ingestion: Form fields on the landing page are explicit dummy inputs that discard values immediately without logging or transmitting.
  • Educational Purpose Only: Design strictly prevents reuse as a functional credential harvesting or campaign delivery tool.

⚙️ Core Architecture Components

  • Flask Core Web Application: Lightweight Python routing server.
  • SQLite Database Storage: In-memory / local persistent relational schema for users, emails, telemetry, and incident state.
  • Telemetry & SIEM Exporter: Real-time structured event logging with CSV and JSON formatting.
